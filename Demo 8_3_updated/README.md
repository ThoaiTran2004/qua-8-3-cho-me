# 🌸 Món Quà 8/3 Đặc Biệt: QR Code & Bó Hoa Ảo Diệu 🌸

Một dự án độc đáo để tạo lời chúc 8/3 cho mẹ với hiệu ứng hoa nở từ các nhánh rồi chụm lại thành bó hoa đẹp mắt!

## 📁 Các file trong dự án:

- `index.html` - Trang chính hiển thị mã QR lớn để quét
- `flower-bloom.html` - Trang web với hiệu ứng hoa nở từ nhánh rồi chụm lại thành bó hoa
- `qrcode_generator.html` - Công cụ tạo QR Code tùy chỉnh (không cần dùng nữa)
- `README.md` - Hướng dẫn sử dụng chi tiết

## 🎯 Cách hoạt động:

### Luồng trải nghiệm:
1. **Trang 1 (`index.html`)**: Hiển thị mã QR lớn đẹp mắt với hiệu ứng tim bay và lấp lánh
2. **Quét mã QR**: Mẹ dùng điện thoại quét mã QR
3. **Trang 2 (`flower-bloom.html`)**: Hiệu ứng hoa nở từ các nhánh rồi chụm lại thành bó hoa
4. **Kết quả**: Lời chúc 8/3 ý nghĩa với ảnh và nhạc nền

## 🚀 Cách sử dụng:

### Bước 1: Xem trước trang chính
1. Mở file `index.html` trong trình duyệt
2. Bạn sẽ thấy:
   - Mã QR lớn ở trung tâm
   - Hiệu ứng tim bay liên tục
   - Hiệu ứng lấp lánh vàng
   - Hướng dẫn chi tiết
   - Mã QR tự động tạo và dẫn đến trang hoa nở

### Bước 2: Xem trước trang hoa nở
1. Mở file `flower-bloom.html` trong trình duyệt
2. Bạn sẽ thấy:
   - Các nhánh hoa mọc lên từ từ
   - Hoa nở lần lượt trên từng nhánh
   - Sau 6 giây, các hoa chụm lại thành bó hoa
   - Ảnh mẹ hiện ra với hiệu ứng xoay đẹp
   - Lời chúc 8/3 xuất hiện
   - Nhạc nền có thể bật/tắt
   - Cánh hoa rơi và tim bay

### Bước 3: Deploy để sử dụng thật
Để mã QR hoạt động trên mọi thiết bị, bạn cần tải trang web lên hosting:

**Cách 1: GitHub Pages (Miễn phí)**
1. Tạo tài khoản GitHub
2. Tạo repository mới
3. Upload tất cả các file lên repository
4. Vào Settings → Pages → Source: Deploy from a branch
5. Chọn main branch và save
6. Copy URL và chia sẻ cho mẹ

**Cách 2: Netlify (Miễn phí)**
1. Vào netlify.com
2. Kéo thả thư mục dự án vào
3. Copy URL được cung cấp

**Cách 3: Vercel (Miễn phí)**
1. Vào vercel.com
2. Import project từ GitHub
3. Deploy và copy URL

### Bước 4: G tặng mẹ
1. Gửi URL trang chính cho mẹ
2. Hoặc in mã QR ra giấy
3. Mẹ quét mã và tận hưởng sự bất ngờ!

## 🎨 Tùy chỉnh:

Thay bằng ảnh của bạn.

Trong file `flower-bloom.html`, tìm dòng:

Thay bằng link nhạc bạn muốn.
