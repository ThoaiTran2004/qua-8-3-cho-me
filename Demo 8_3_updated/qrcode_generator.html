🌸 Tạo QR Code Chúc Mừng 8/3 🌸

📋 Hướng dẫn sử dụng:

  1. Nhập đường dẫn đến trang web chúc mừng 8/3 của bạn
  2. Nhấn nút "Tạo QR Code"
  3. Lưu QR Code về máy bằng nút "Tải QR Code"
  4. In QR Code ra giấy hoặc gửi cho mẹ qua điện thoại
  5. Mẹ chỉ cần quét mã QR bằng điện thoại để xem lời chúc!
💡 Lưu ý: Để QR Code hoạt động, bạn cần tải trang web lên một hosting miễn phí như GitHub Pages, Netlify, hoặc Vercel.
