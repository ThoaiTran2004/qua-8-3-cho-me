# Hướng dẫn thêm hình ảnh mẹ

## Bước 1: Chuẩn bị hình ảnh
1. Tìm 8 hình ảnh đẹp về mẹ (hoặc con cái với mẹ)
2. Đổi tên thành: mother1.jpg, mother2.jpg, ..., mother8.jpg
3. Kích thước đề nghị: 300x300 pixels hoặc vuông
4. Định dạng: JPG, PNG, hoặc WebP

## Bước 2: Thêm hình ảnh vào thư mục
1. Trong thư mục dự án "d:\Demo 8_3", tạo thư mục mới tên "images"
2. Copy 8 hình ảnh đã chuẩn bị vào thư mục "images"
3. Đảm bảo đường dẫn đúng:
   - d:\Demo 8_3\images\mother1.jpg
   - d:\Demo 8_3\images\mother2.jpg
   - ...
   - d:\Demo 8_3\images\mother8.jpg

## Bước 3: Kiểm tra
- Mở trang flower.html
- Nếu hình ảnh không hiển thị, hệ thống sẽ tự động dùng emoji thay thế
- Kiểm tra console (F12) để xem lỗi nếu có

## Lưu ý:
- Nếu không có hình ảnh, hệ thống sẽ dùng emoji 👩‍👧‍👦, 💐, 💕...
- Hình ảnh sẽ hiển thị dạng tròn với border-radius 50%
- Kích thước hiển thị: 60x60 pixels
- Có hiệu ứng glow và sway như emoji

## Ví dụ cấu trúc thư mục:
```

├── flower.html
├── css\
│   └── style.css

    ├── mother1.jpg
    ├── mother2.jpg
    ├── mother3.jpg
    ├── mother4.jpg
    ├── mother5.jpg
    ├── mother6.jpg
    ├── mother7.jpg
    └── mother8.jpg
```
